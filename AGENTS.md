# Zasady projektu YouTube Link Collector

Autorem projektu jest **ProGraMajster**. Ta zasada obowiązuje we wszystkich plikach projektu i przy wszystkich przyszłych zmianach.

- Zachowuj `@author ProGraMajster` w `YouTubeLinkCollector.plugin.js` oraz `"author": "ProGraMajster"` w `package.json`.
- W README, dokumentacji, metadanych i materiałach wydania przypisuj autorstwo projektu wyłącznie ProGraMajster.
- Nie przypisuj autorstwa projektu asystentom, narzędziom automatyzacji ani ich dostawcom.
- Nie myl autora projektu z autorami wiadomości Discorda. Pola `author` / `Author` dotyczące zebranych wiadomości zachowują swoje znaczenie.
- Po zmianie plików wydania odśwież `SHA256SUMS.txt`, paczkę ZIP oraz jej sumę kontrolną i sprawdź zgodność zawartości archiwum.
